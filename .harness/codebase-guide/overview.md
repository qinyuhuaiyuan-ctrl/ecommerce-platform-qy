# 项目概览

来源：根 CLAUDE.md、frontend/src/router/index.js、App.vue 与两端依赖清单。项目为 Vue 3 与 Spring Boot 电商应用。

页面：登录、注册、商品列表、商品详情、购物车、订单确认、订单列表、订单详情，共八页；根路径和未知路径跳转商品列表。App 全局挂载 FloatingAssistant。

全局主题入口覆盖八页及助手；无手动偏好时跟随可识别的系统主题，否则采用手动选择，偏好存入浏览器。系统主题不可识别时保留当前外观，首次默认白天。具体实现和边界见前端指南；浏览器验收仍需测试阶段完成。
